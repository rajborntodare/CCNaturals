# 🧬 CC Naturals AI — Android App

Smart cosmetic R&D scientist + regulatory compliance engine.

## Build APK via GitHub (no local setup needed)

1. Create a GitHub repo and upload ALL files (including `.github/` folder)
2. Go to **Actions** tab → watch the build run (~6 min)
3. Download **CCNaturals-AI-debug-apk** from Artifacts
4. Install on Android → enter your Anthropic API key → formulate!

## Features
- 🧬 Full formula generation with INCI list, phases, percentages
- ✅ Compliance dashboard (EU Annexes, FDA, Sephora Clean, Credo, Ulta, custom)
- 📎 Upload restriction documents (PDF, DOCX, CSV, TXT) — AI reads and enforces all rules
- 🔄 Ingredient replacement with auto re-validation
- 🏭 Batch process design with temperatures and mixing protocols
- 💾 Persistent formula library

## API Key
Get yours at **console.anthropic.com** → API Keys → Create Key
Add billing at **console.anthropic.com/billing** (required to activate)
